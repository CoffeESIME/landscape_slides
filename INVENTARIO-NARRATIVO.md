# Inventario y decisión previa

Se conserva React + Vite, SceneView, navegación por pasos/hash, Drawer, useAudio, fuentes locales, manifiesto de medios y compilación offline. No se elimina ningún renderer.

| Escenas existentes | Decisión |
|---|---|
| preludio, primera-mirada, regreso, cierre | Editar para el título y experimento Kailash–Iztaccíhuatl; cierre nuevo |
| animales, miedo, asombro, yo, alteridad, poder | Reutilizar y condensar |
| natural, atraccion | Fusionar con poder y miedo; originales archivados |
| perspectiva-refugio | Pasar a notas de biofilia |
| dos-horas, amar, pantalla, cuerpo, escuchar, tiempo, memoria, cuidar | Material complementario; sin borrar renderers |
| lugar-perdido | Reutilizar en valorar |
| muchos-mundos, niyamgiri | Complementario, conservando todas sus fuentes |
| wirikuta | Complementario opcional |
| ave | Reemplazar en el flujo por BirdReveal configurable; original archivado |
| poesia, bosque-poema | Conservar pausas; marcadores solo en desarrollo |
| caminar, goce | Reutilizar y acercar a la ciudad |

Los 30 registros originales se preservan en src/data/archive/presentation.ts.
